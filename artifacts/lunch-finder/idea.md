# 직장인 점심 추천기 (lunch-finder)

## Problem Statement
고물가 시대에, 매일 점심 결정을 반복해야 하는 직장인이 — 예산 걱정 없이 —
30초 안에 근처 식당 한 곳을 고를 수 있게 할 수 있을까?

## Recommended Direction
개인 큐레이션 DB + 간단한 추천 룰의 조합.

카카오 로컬 API로 위치/기본 정보를 가져오되, 메뉴 가격은 직접 등록한다.
"내가 직접 쓸 도구"이므로 주변 30-50개 식당 큐레이션이면 충분하다.
AI 추천은 "최근 3일 안 간 곳 + 1만원 이하 + 카테고리 다양성" 룰베이스로
시작하고, 데이터가 쌓이면 개선한다.

## Key Assumptions to Validate
- [ ] 카카오 로컬 API가 유용한 기본 데이터를 제공하는가 → API 문서 확인 + 테스트 호출
- [ ] 30-50개 식당 직접 입력이 실용적인가 → MVP 직접 사용해보기
- [ ] 룰베이스 추천이 "그냥 목록 보기"보다 실제로 더 나은 경험인가

## MVP Scope
포함:
- 카카오 로컬 API로 근처 식당 검색
- 식당별 메뉴/가격 직접 등록 (간단한 CRUD)
- 1만원 이하 필터
- 최근 방문 기록 + 카테고리 기반 단순 추천

빠짐:
- 실시간 가격 크롤링
- 배달 기능
- 소셜/공유 기능

## Not Doing (and Why)
- 실시간 크롤링 — 법적 리스크 + 유지 비용, 개인 도구에 불필요
- 배달 기능 — 배민/쿠팡이 이미 잘 함
- 리뷰/별점 — 혼자 쓰는 도구에 오버엔지니어링
- 소셜 기능 — 목적이 팀 도구가 아님

## Open Questions
